- Baslik: Show HN: CADdy - An AI assistant inside FreeCAD that measures its own work
- URL alanina repo linki; ilk yorumu kendin yaz (metin asagida).

Ilk yorum:

  Hi HN, I made CADdy because I kept asking chat models for FreeCAD
  scripts, pasting them in and getting parts that looked right but
  weren't: faces turned inside out, an open shell, two pieces that
  overlapped by a few mm3 where you can't see it.

  CADdy is a panel inside FreeCAD 1.1. You describe what you want, it
  writes FreeCAD Python and runs it on the document you have open. Your
  own features and the AI's end up in the same tree. It then checks the
  result with actual measurements instead of trusting a screenshot:

  - topology validity, the volume sign of each solid (catches inside-out
    solids that isValid() accepts), open shells
  - mesh printability (closed, self-intersections, components)
  - part-to-part overlap using boolean common + section + distance.
    Early on the model looked at renders and said "no overlap" twice;
    both times it was wrong.
  - anything it could not check is reported as NOT RUN, never silently
    skipped

  Every AI turn is one transaction, so a single Ctrl+Z undoes all of it,
  and the panel's undo never touches your own edits.

  It runs on the Claude Code CLI with your Claude subscription; there is
  no API key to set up. Windows only for now; macOS/Linux mostly needs
  the installer and the CLI lookup ported (open issue).

  Most of what I use it for is 3D-printing parts and quick concept
  models. I'd really like to hear from people who use FreeCAD daily:
  where does it break, and what would you want it to check that it
  doesn't?
